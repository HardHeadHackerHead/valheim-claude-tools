# Claude Tools (the mod)

The in-game half of [Claude Tools for Valheim](../../README.md): install, settings and everything it does are on the repo's front page.

- `CLAUDE.md`: the guide the mod writes to `BepInEx/claude/CLAUDE.md` for the assistant (every command, how requests work).
- `CHANGELOG.txt`: every change; its top paragraph is what the mod manager shows when an update is waiting.
- `DESCRIPTION.txt`: the text on the mod's card in the mod manager.
- `Shipped/patchmap.json.gz`: what the top 100 Thunderstore mods patch (facts only), made by `tools/PatchMap`.
- The skills and templates it carries are at the repo's top: [skills/](../../skills/) and [templates/](../../templates/).
